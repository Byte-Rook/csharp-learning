# Lesson07 — İlk Hafta Tekrarı

Bu bölüm, Lesson01–06 kapsamında çalışılan kavramları bir araya getirir.
Ayrı bir konsol uygulaması içermez.

## Konu Özeti

| Kavram | Kullanımı |
| --- | --- |
| Console.Write / WriteLine | Konsola çıktı verme |
| Console.ReadLine | Kullanıcıdan metin okuma |
| string, int, decimal, bool | Uygun veri türünü seçme |
| Convert | Metni sayısal değere dönüştürme |
| if / else if / else | Koşullara göre karar verme |
| && / || / ! | Mantıksal koşulları birleştirme |
| for / while / foreach | Tekrarlı işlemler |
| Metot ve parametre | İşlemleri yeniden kullanılabilir parçalara ayırma |
| return | Sonucu çağıran koda döndürme |
| List<T> | Birden fazla değeri birlikte tutma |

## Tekrar Kontrol Listesi

- [ ] Kullanıcıdan alınan metin ile sayısal değeri ayırt edebiliyorum.
- [ ] Atama ile eşitlik karşılaştırmasının farkını açıklayabiliyorum.
- [ ] Duruma uygun döngüyü seçebiliyorum.
- [ ] Toplamı ve sayacı döngü boyunca güncelleyebiliyorum.
- [ ] Parametre ile argüman arasındaki farkı biliyorum.
- [ ] void ile değer döndüren metotları ayırt edebiliyorum.
- [ ] Liste üzerinde toplam, ortalama ve min/max hesabını takip edebiliyorum.

## Örnekleri Çalıştırma

Depo kökünden:

```bash
dotnet run --project Lesson06
```

Önceki derslerdeki basit `Convert` örnekleri hatalı girişte exception
oluşturabilir. Güvenli giriş kontrolü Lesson11'de ele alınır.
