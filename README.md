## Çalıştırma

İlgili projenin `.csproj` dosyasında belirtilen hedefle uyumlu .NET SDK kurulmalıdır.

Ana klasörden bir ders çalıştırmak için:

```bash
dotnet run --project Lesson14
```

Başka bir ders için `Lesson14` yerine ilgili klasör adını kullanın.
Lesson07 bir tekrar belgesidir; çalıştırılabilir proje içermez.
